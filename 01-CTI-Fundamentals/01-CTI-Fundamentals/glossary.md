# CTI Glossary

This glossary contains key terms related to Cyber Threat Intelligence (CTI) and phishing infrastructure analysis.

| Term | Definition |
|---|---|
| **Cyber Threat Intelligence (CTI)** | Information about cyber threats that is collected, processed, analyzed, and used to support cybersecurity decisions. |
| **Threat Actor** | An individual, group, or organization that conducts or supports malicious cyber activities. |
| **Threat** | A potential event, action, or actor that may cause harm to an information system or organization. |
| **Threat Intelligence** | Processed and analyzed information about threats that provides useful context for cybersecurity operations. |
| **Indicator of Compromise (IOC)** | A piece of information that may indicate malicious activity or a security compromise, such as an IP address, domain, URL, or file hash. |
| **Tactics, Techniques, and Procedures (TTPs)** | The behaviors and methods used by threat actors to conduct cyber attacks. |
| **Malware** | Malicious software designed to perform unauthorized or harmful actions on a computer system. |
| **Phishing** | A social engineering technique that attempts to trick users into revealing information or performing an unwanted action, often through fraudulent messages or websites. |
| **Phishing Infrastructure** | The technical infrastructure used to support phishing campaigns, including domains, IP addresses, hosting services, URLs, and web servers. |
| **Domain** | A human-readable address used to identify a website or other Internet resource. |
| **IP Address** | A numerical address assigned to a device or network interface on a network. |
| **URL (Uniform Resource Locator)** | An address that identifies a resource available on the Internet. |
| **OSINT (Open Source Intelligence)** | Intelligence collected from publicly available information sources. |
| **Attack Vector** | The method or path used by a threat actor to gain access to a target or deliver a malicious action. |
| **Threat Actor Group** | A group of individuals or organizations associated with specific malicious cyber activities. |
| **Command and Control (C2)** | Infrastructure or communication mechanisms used by attackers to communicate with compromised systems. |
| **Malicious Domain** | A domain associated with malicious activities such as phishing, malware distribution, fraud, or command and control. |
| **Payload** | The part of an attack that performs the intended malicious action after successful delivery or execution. |
| **Vulnerability** | A weakness in a system, application, configuration, or process that can potentially be exploited. |
| **Exploit** | A technique, code, or method used to take advantage of a vulnerability. |
| **Threat Intelligence Platform (TIP)** | A platform used to collect, organize, correlate, analyze, and share threat intelligence data. |
| **MISP** | An open-source platform designed for collecting, storing, correlating, and sharing threat intelligence and IOCs. |
| **STIX** | A standardized language and format for representing and exchanging cyber threat intelligence. |
| **TAXII** | A protocol designed to exchange cyber threat intelligence in a standardized way. |
| **Threat Landscape** | The overall environment of cyber threats, threat actors, attack methods, vulnerabilities, and trends affecting organizations or systems. |
| **Attribution** | The process of assessing which threat actor, group, or source may be responsible for observed malicious activity. |
| **False Positive** | An alert or indicator incorrectly classified as malicious or suspicious. |
| **False Negative** | Malicious activity that is incorrectly classified as legitimate or not detected. |
| **Data Source** | A source from which information used for threat intelligence is collected. |
| **IOC Enrichment** | The process of adding additional context and information to an indicator to improve its analysis and usefulness. |
